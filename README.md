# Ciglan.sk 2025

A modern web app built with React, Vite, and styled with Tailwind CSS.

🚀 Features

- Simple onClick presentation of services.
- Responsive design for mobile, tablet, and desktop.
- Responsive navigation using React Router.
- Contact form powered by EmailJS.
- Gallery page using Yet-Another-Gallery plugin.
- Image Slider component with array of pictures (navigate by click or interval).
- Notification component displayed when form is submitted.
- Banner component with Router Link to form section.
- ScrollToTop component to scroll to top when navigating to a new page.

🛠️ Built with

- React
- Tailwind CSS
- React Router
- Yet-Another-Gallery plugin
- Framer Motion animations
- Deployed on ciglan.sk via Netlify
